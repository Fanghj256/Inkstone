# 003-notes · 核心内化层

这里是你**自己的思考**，不是收藏。

## 什么算一条 note

- 你想明白的一个判断："为什么我们组不该上 K8s"
- 一次排障的完整因果链：现象 → 排查路径 → 根因 → 下次怎么更快
- 准备公开发布的草稿（长推、博客、分享稿）

## 什么不算

- 从别处复制的一段话（那属于 `002-references/`）
- 没有结论的链接堆（那属于 `001-inbox/`）

## 写法建议

不用模板。真要一个，就三行：

```
结论：
为什么：
什么情况下不成立：
```

第三行最重要。写不出"什么情况下不成立"，说明你还没真的想透。

内化完成的标志：\*\*能对着一个外行讲清楚，且对方能复述。\*\*
