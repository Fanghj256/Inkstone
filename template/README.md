# 我的知识库

四层目录，按"输入 → 内化 → 输出 → 归档"分层。
外部一手资料和自己的思考**物理隔开**，避免格式和内容混杂。

| 目录 | 放什么 |
|---|---|
| `001-inbox/` | 随手念头、踩坑原话、待处理的碎片 |
| `002-references/raw/` | 抓下来的一手原文，按来源分目录 |
| `002-references/files/` | 直接发过来的 PDF / Word |
| `002-references/failed/` | 抓取失败的记录，附 URL 和原因 |
| `003-notes/` | 自己想明白的、准备输出的内容 |
| `004-archive/` | 已公开发布的内容 + 读者反馈 |

## 三条规矩

1. **`002-references/raw/` 只读。** 原文一旦被改写，就再也无法核查。
2. **不发摘要进 raw。** 想总结写在 `003-notes/`。
3. **不维护复杂标签字典。** 全局搜索够用。

`AGENTS.md` 是写给 AI 助手的，任何 agent 在这个目录里干活前都会先读它。

## 版本管理

这就是一个普通的 git 仓库：

```bash
git init -b main
git add -A
git commit -m "init"
```

远端建议建**私有**仓库（GitHub 或国内更稳的 Gitee），只给自己看。
